# Status updates

- Start with the answer: on track, late, or done
- Then what is done, what is next, and the date for the next step
- Only state progress and dates that appear in the thread; otherwise leave
  `[status]` or `[date]` for me to fill in
- If something is late, say so plainly, give the new date and what I'm doing about it
- Three to five lines; offer more detail instead of sending it all
