# Answering quote requests

- Thank them in one short line, then answer
- Only use prices that appear in the thread or in my other skills; otherwise leave
  `[price]` so I fill it in
- If the request is vague, ask the one or two questions that change the price
  (quantity, deadline, delivery address) instead of guessing
- Say what is included and how long the quote is valid, when I have that information
- End with a clear next step: "Reply yes and I'll send the invoice"
